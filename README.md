# Event Ticketing API 🎟️

## 📌 Overview
This is the backend API for an Online Event Ticketing Application. It handles user authentication, event management, ticket booking, and payment processing.

## 🚀 Features
- User registration and login (JWT Authentication)
- Event creation and management (Admin)
- Ticket booking system
- Payment integration
- Order history
- Secure API endpoints
-
